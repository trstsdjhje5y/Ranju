RAKESH J K — PERSONAL PORTFOLIO

FILES
- index.html: website content
- style.css: layout, colors, responsive design, animations
- script.js: mobile navigation, copyright year, demo contact form

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted my-portfolio folder.
3. Double-click index.html to open it in your browser.
   Or open the folder in Visual Studio Code and use the Live Server extension.

CUSTOMIZE
- Edit index.html to update your name, education, skills, and projects.
- Edit style.css to change colors and design.
- Edit script.js to change interactions.
- Replace the sample project descriptions with your actual projects.

IMPORTANT
The contact form is a front-end demo only. It does not send emails or store messages.
Google Fonts require an internet connection; the website still works with fallback fonts.
